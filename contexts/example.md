# Meeting context: REPLACE ME with the purpose

Copy this file to `contexts/default.md` for criteria shared by all recordings,
then fill it in. You may also add `contexts/<recording name>.md` with facts
specific to one meeting; evaluation combines it with the shared context.

The evaluation is only as useful as this file. The scripts refuse to run while
the string `REPLACE ME` is present. Delete sections you do not need.

## Purpose and background

REPLACE ME — why the meeting happened, what preceded it, and what a useful
outcome would look like.

## Subject of the evaluation

REPLACE ME — state exactly what should be assessed: a proposal, decision,
project, vendor, candidate, team process, customer need, or something else.
Name the relevant participant or artifact when ambiguity is possible. If this
is only a meeting recap and nothing should be scored, use `bin/summarize.sh`
instead of the evaluation stage.
